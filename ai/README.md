# Previa AI, Data & Automation (Person 3 / Agent 3)

## 📌 Ownership
- **Owner**: Person 3 / Agent 3 (AI/Data & Automation)
- **Tech Stack**: Python 3.11+, Tesseract / EasyOCR, OpenCV, Pandas, Scikit-learn, Rule Engine

## 🎯 Scope & Responsibilities
- Insurance card OCR image pre-processing and field extraction (`/api/ocr/insurance-card`).
- Field-level intelligent validation engine (`/api/validation/insurance`).
- Deterministic weighted Risk Engine (`0–100`) and explainable factor breakdown (`/api/risk/evaluate`).
- Recommended Action Engine (`/api/clearance/evaluate`).
- Historical claim denial pattern clustering & Root Cause Analysis (RCA) (`/api/analytics/denials`, `/api/analytics/root-causes`).
- Preventive workflow automation triggers and impact tracking.
- Synthetic healthcare dataset generation in `data/`.

## 🛡️ AI Boundary Policy
- LLMs are strictly advisory/explanatory. Deterministic algorithms own all clearance, risk scores, and eligibility calculations.
