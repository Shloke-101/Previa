# Previa Frontend (Person 2 / Agent 2)

## 📌 Ownership
- **Owner**: Person 2 / Agent 2 (Frontend)
- **Tech Stack**: Next.js 14+ (App Router), React, Tailwind CSS, Recharts, Lucide React

## 🎯 Scope & Responsibilities
- Pre-visit priority work queue and real-time clearance status badges (`CLEARED`, `NEEDS_ACTION`, `HIGH_RISK`).
- Insurance card upload UI with visual OCR bounding box previews and field validation badges (`MATCH`, `PARTIAL_MATCH`, `MISMATCH`).
- Patient dossier view with real-time verification breakdown, procedural coverage, and deductible/copay financial estimates.
- Explainable risk meter visualization with contributing factor bars.
- Systemic root-cause denial analytics dashboard & preventive workflow toggle controls.

## 🔗 Connected Contracts
- Consumes contracts defined in `contracts/*.schema.json` and REST endpoints in `contracts/api_spec.json`.
