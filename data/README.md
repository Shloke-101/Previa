# Synthetic Data & Mock Data Layer

This directory stores purely synthetic healthcare test scenarios, mock payer rules, and historical denial datasets.

> [!IMPORTANT]
> **Zero Real PHI Rule**: This repository must ONLY contain synthetic / simulated healthcare records.

## 📂 Contents
- **`synthetic_seed_template.json`**: Standard demo scenarios covering Cleared, Missing Auth, Data Mismatch, Expired Insurance, and Systemic Denial patterns.
- **`historical_denials.json`** *(Phase 1/4)*: 300+ simulated historical claim denials for root cause clustering demo.
